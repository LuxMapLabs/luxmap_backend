# BE-24 — ảnh của phiếu công việc (Claude, 04/10/2026)

Quyết định của Mỹ (04/10): thêm `kind = observation` (EV-1), thêm danh sách + xem ảnh qua API, phiếu sửa chữa bắt buộc ảnh `after`.
Drift **BE-24** (SELF-SIGNED).

## Đã làm
- Bảng `repair_evidence` (migration `AddRepairEvidence`): ID `EVD-…` từ sequence; FK ghép `(work_order_id, commune_id)` → phiếu
  (cùng xã theo lược đồ); FK `uploaded_by` → `app_user`; CHECK toạ độ (chặn luôn NaN/Infinity), số byte > 0; unique partial
  `(uploaded_by, client_op_id)` **kèm index FK `uploaded_by` khai tường minh** (partial index không thay được index FK).
- `WorkOrderEvidenceService`: upload (kiểm hình dạng → phiếu qua query filter → người được giao → khoá lặp → nhãn theo loại phiếu
  → `in_progress` → cấp ID → ghi object (thumbnail bỏ EXIF, gốc nguyên byte) → ghi hàng), danh sách, mở ảnh qua phiếu cha.
- `WorkOrderService.Act("complete")`: phiếu sửa chữa thiếu ảnh `after` → 409 `AFTER_EVIDENCE_REQUIRED`.
- `EvidenceController`: `/evidence/{id}/thumbnail|original`. OpenAPI: bỏ stub `ni(...)` và schema viết tay `EvidenceUpload`.

## Codex review (bốn lượt, `-c model="gpt-6-astra"`)
1. Ghi ảnh xong không kiểm lại phiếu — Quản lý giao lại/huỷ giữa lúc tải vẫn lưu được ảnh. **Sửa:** khoá `work_order`, đọc lại qua
   filter, kiểm lại người được giao và `in_progress` (khuôn P2a). Test đổi phiếu giữa lúc ghi ảnh (giao lại → 404, huỷ → 409).
2. JPEG có chữ ký đúng nhưng hỏng ruột ra 500; `captured_at = "13:30"` được nhận kèm ngày hôm nay. **Sửa:** `ImagePipeline` dịch lỗi
   giải mã thành 415 (ảnh khảo sát hưởng luôn; test hỏng + bị cắt trong Storage.Tests); `captured_at` phải là ngày-giờ ISO 8601 đầy đủ.
3. Hai lần gửi lại cùng `client_op_id` chồng nhau, phiếu vừa hoàn thành → lần sau nhận 409 thay vì ảnh đã lưu. **Sửa:** kiểm lặp lại
   dưới khoá trước kiểm trạng thái. Test mô phỏng.
4. Sạch.
