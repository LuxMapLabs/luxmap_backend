## 5. Đề xuất (bổ sung, không đổi gì đã có)

**A. `latest_run` trên `GET /sweeps/{id}`** (chỉ chi tiết; danh sách giữ nhẹ) — đóng G-1, G-3:

```json
"latest_run": {
  "run_id": 42, "attempt": 2, "result_state": "failed", "stage": "clock", "error_code": "CLOCK_RESIDUAL",
  "started_at": "…Z", "finished_at": "…Z",
  "coverage_pct": null, "detection_coverage_pct": null, "dim_coverage_pct": null, "coverage_reason": null
}
```

`null` khi chưa có run. Mã lỗi là **danh sách mở** (ghi trong drift, không enum khoá) — pipeline còn thêm mã.

**B. `GET /sweeps/{id}/coverage?run_id=`** (mặc định run thành công mới nhất, như `results`) — đóng G-2:

```json
{ "sweep_id": "SWP-…", "run_id": 42, "coverage_pct": 87.5,
  "segments": [ {
      "segment_id": "SEG-003", "length_m": 812.0, "covered_ratio": 0.83,
      "passes": [ { "pass_no": 0, "direction": "forward", "from_m": 0.0, "to_m": 640.2 } ],
      "gaps":   [ { "from_m": 640.2, "to_m": 812.0, "geometry": { "type": "LineString", "coordinates": [[lng, lat], …] } } ],
      "poles_expected": 24, "poles_observed": 21, "not_observed_pole_ids": ["POLE-0101", "…"] } ] }
```

- `geometry` của khoảng trống = `ST_LineSubstring` trên `geom` **4326** theo phân số — toạ độ ra API vẫn 4326 (BE-10 quy tắc 3); WP5 tô thẳng lên bản đồ.
- Quyền: `ReadSurveys`, cùng luật "phủ cả run" của `results` (tuyến liên xã: thiếu một xã ⇒ không xem được) — dùng lại `SurveyMediaAccess`.
- Không phân trang: một sweep có vài tuyến.

**C. Không làm ở BE-17:** bước hiện tại trong lúc chạy (G-4 — polling `processing_status` đủ cho giai đoạn 1, Contract đã chọn polling);
độ phủ tuyến qua nhiều sweep (G-5 — để dashboard BE-29 / màn bản đồ dùng `last_seen_at`).

**D. Đóng O-4:** `processing_status` = 5 giá trị hiện có — ghi vào drift, lên Contract ở version sau.
