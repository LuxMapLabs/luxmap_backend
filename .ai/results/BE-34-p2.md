**Migration** trên DB nháp `luxmap_be34_scratch` (không đụng `luxmap_dev`):

- up → down → up đều `Done`.
- Đã chèn được: `node_firmware` hash NULL, `lux_module_firmware` hash NULL.
- Bị CHECK chặn:
  - `cv_model` hash NULL → `ck_artifact_version_hash`;
  - `cv_model` hash `abc` → `ck_artifact_version_hash`;
  - `wifi_firmware` → `ck_artifact_version_component`;
  - `node_firmware` version rỗng → `ck_artifact_version_hash`.
- `Down()` khi đã có dòng firmware: `AddVersionTraceability cannot be rolled back`, migration giữ nguyên.
- `UPDATE` registry → `Processing records are immutable`.

**Hai lỗi chính phép thử migration bắt được:**

- **CHECK để lọt `cv_model` không hash.** `NULL ~ regex` cho ra NULL, `NULL OR false` cũng là NULL, mà Postgres coi CHECK NULL là
  **qua**. Đã sửa bằng cách thêm `artifact_hash IS NOT NULL` vào nhánh so khớp.
- **`AlterColumn` sang NOT NULL trong `Down()` bị trigger bất biến chặn**, kể cả khi bảng không có dòng nào: EF sinh `UPDATE … WHERE …
  IS NULL` trước. Đã thay bằng `ALTER … SET NOT NULL` trần.
