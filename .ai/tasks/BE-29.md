## Yêu cầu (Phase 1)

Khảo sát, đề xuất hình dạng API + nguồn số liệu + lược đồ, ghi D-item. Kết quả: `.ai/results/BE-29-p1.md`. Phải trả lời:

1. "Mật độ điểm tối" tính trên cái gì: trạng thái **lần quan sát công bố gần nhất** của cột (`out` / `dim`; `unknown` đếm riêng, không gộp vào `out`),
   theo ô lưới / theo đoạn đường / theo xã? Chi phí truy vấn so với yêu cầu `< 500 ms với 2000 cột`.
2. "Nút giao / cầu chưa có đèn": dữ liệu nào nói chỗ đó là nút giao / cầu? Nếu repo **không có** nguồn này, nói thẳng và nêu các phương án
   (thêm bảng / thuộc tính, suy từ topology tuyến, bỏ khỏi phạm vi) kèm giá — đừng tự chọn.
3. Hình dạng response (GeoJSON như `/map/…` hay JSON phân trang như thống kê), tham số, `bbox` có bắt buộc không, lọc `data_source`.
4. Capability nào (đối chiếu `LuxMapPolicies.Matrix`), phạm vi xã.
5. Có cần migration / index mới không (ước lượng, chưa viết).
